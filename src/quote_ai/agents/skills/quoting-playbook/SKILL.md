# DBxLab quoting playbook (demo data)

## Presenting options
- Present up to three eligible options, cheapest compliant first.
- Always show unresolved evidence; never describe "unknown" as fine.
- An option that misses the delivery date is an alternative: say so, with the date it can ship, and that the
  customer has to accept it.

## Discounts
- Explain the band from price_quote; above the band, say a manager approval is required (AI-21).
- Never promise a price. The price is price_quote's number; the band is the pricing policy's answer.
- How to talk about a discount request: see discount-talk.md.

## Substitutions
- Only between eligible SKUs; name the difference (thickness, cuff length, fulfilment).

## When to escalate
- A discount above the rep's limit: a manager approves that exact quote version.
- Anything below the margin floor: refused by policy; no approval can override it. Say so plainly.
